# Бенчмарки

Измерительные стенды, которыми получены числа из [docs/](../docs/). Каждый
меряет одну вещь в изоляции; образцами кода они не являются.

```bash
cargo bench --bench index-width
```

Это обычные программы с `fn main()`, а не функции `#[bench]`, — поэтому в
`Cargo.toml` у них стоит `harness = false`.

| Бенчмарк | Что меряет |
|---|---|
| `field-bench` | умножение в поле: скаляр против NEON и AVX2 |
| `gpu-chain` | ядро для видеокарты отдельно от всего |
| `hit-rate` | частоту попаданий фильтра против теории |
| `index-width` | пропускную способность от ширины индекса |
| `master-load` | сколько запросов держит мастер |
| `match-bench` | матчинг с индексом против простого перебора |
| `regex-cost` | во что обходится регулярное выражение против литерала |
| `score-calibration` | таблицу соответствия оценки измеренной доле |
| `store-rate` | запись находок: папки с ключами против строк в базе |
| `substring-scaling` | поиск вхождения от числа фильтров |
